Página de ventas (Landing Page) interactiva, moderna y ultra-optimizada para dispositivos móviles para el producto digital: **"Lives con IA en TikTok Shop: Sistema No-Face de Transmisión Continua"**.

## ✨ Características y Secciones

1. **Header & Urgencia:** Banner superior dinámico con temporizador regresivo de escasez (8:42 min).
2. **Hero Section:** Titular gancho de alta conversión, badges con animación pulsante y CTA directo.
3. **Prueba Social en Tiempo Real:** Notificaciones flotantes animadas tipo toast ("Carlos M. compró hace 2 min").
4. **Calculadora Interactiva de Ganancias:** Permite al visitante ajustar horas de live y tasa de comisión con sliders para ver sus ingresos diarios y mensuales estimados en tiempo real.
5. **Módulos del Manual:** Desglose visual de los 7 módulos del sistema paso a paso.
6. **Módulo de Bonos Exclusivos:**
   - Bono 1: Pack de Prompts Secretos para Midjourney / Leonardo AI (47€ Valor).
   - Bono 2: Plantillas de Guiones AIDA de Persuasión (39€ Valor).
   - Bono 3: Directorio de 25 Proveedores VIP con 18%+ comisión (67€ Valor).
7. **Garantía de 7 Días:** Sello de garantía incondicional de satisfacción o reembolso total.
8. **Checkout Modal Interactivo:** Simulación de pasarela de pago segura con descarga directa del manual en PDF.
9. **Barra Sticky Inferior:** Barra flotante fija para compras directas con un clic en pantallas móviles.

## ⚡ Cómo Ejecutar Localmente

### Opción 1: Abrir directamente en el navegador
Simplemente haz doble clic en el archivo `index.html` o arrástralo a tu navegador web favorito (Chrome, Edge, Safari, Firefox).

### Opción 2: Usar Node.js
```bash
node server.js
```
Luego abre tu navegador en: `http://localhost:8085/index.html`

### Opción 3: Extensión Live Server de VS Code
Abre la carpeta en VS Code y pulsa en **"Go Live"**.

## 🌐 Cómo Desplegar en la Web

### GitHub Pages (100% Gratis)
1. Sube este repositorio a tu cuenta de GitHub.
2. Ve a **Settings** > **Pages**.
3. En **Branch**, selecciona `main` (o `master`) y la carpeta `/ (root)`.
4. Haz clic en **Save**. ¡Tu landing page estará disponible online en segundos!

### Vercel / Netlify
Arrastra y suelta esta carpeta en el panel de [Vercel](https://vercel.com) o [Netlify](https://www.netlify.com) para obtener un enlace `.app` instantáneo con certificado SSL gratuito.
